要約

✔ 通常のタスク管理では、タスクデータを外部へ送信しません
✔ すべてのデータはお使いのブラウザまたはローカルファイルに保存されます
✔ アナリティクス・トラッキングは導入していません
✔ ユーザーアカウントやサーバー側ストレージはありません
✔ 任意のMac向けAIアシスト（AI日付診断を含む）は、事前説明と同意後に必要最小限のタスク情報だけをOpenAIへ送信します

1. はじめに

本プライバシーポリシーは、Chrome拡張機能「CO[:V]」（以下「本拡張機能」）におけるデータの取り扱いについて説明するものです。 本拡張機能は個人開発者 mock-n3 により開発・提供されています。

CO[:V]は、プレーンなMarkdown（.md）ファイルでタスクを管理するChrome拡張機能です。 ユーザーのプライバシーを最大限尊重し、通常のタスク管理を端末内で完結させます。任意のAIアシスト（AI日付診断を含む）をユーザーが明示的に実行した場合だけ、本ポリシーに記載する必要最小限のタスク情報をOpenAIへ送信します。

2. 保存されるデータ

本拡張機能は以下のデータをユーザーのデバイス上にのみ保存します。

データの種類 保存場所 目的
タスクデータ（Markdownファイル） IndexedDB またはローカルフォルダ タスクの管理・表示
拡張機能の設定 Chrome Storage API（ローカル） ユーザー設定の保持
AI APIキー（任意設定） Chrome Storage API（ローカル） AI機能の認証
保存方式について ユーザーは以下の2つの保存方式から選択できます：
  • ブラウザ内部ストレージ（IndexedDB） - ブラウザ内に保存されます
  • ローカルフォルダ（File System Access API） - ユーザーが指定したローカルフォルダに直接保存されます

3. 自動収集しないデータ

ユーザーがタスク本文へ任意に入力した内容を除き、本拡張機能は以下のデータを自動収集しません：

  • 個人を特定できる情報（氏名、メールアドレス等）
  • 閲覧履歴やブラウジングデータ
  • 利用状況に関するアナリティクスデータ
  • 位置情報
  • 端末の識別情報
  • その他いかなる形式のユーザートラッキングデータ
通常のタスク管理では外部サーバーへのデータ送信を行いません。任意のAIアシスト（AI日付診断を含む）については次項をご確認ください。

4. AI連携について

本拡張機能は、macOSで利用できる任意機能「AIアシスト」（タスクプランナー・カスタム指示・AIタスク診断。AIタスク診断のリスケジュールで使うAI日付診断を含む）を提供します。これらの機能は通常のタスク管理には不要であり、ユーザーが送信内容と利用目的を確認して「AIアシストの利用」に同意し、各機能の実行ボタン（「提案を作る」「診断を開始」など）を押した場合だけ実行されます。同意した記録はお使いの端末内にのみ保存され、2回目以降は同意画面を表示しません。送信内容の説明を改訂した場合は、あらためて同意を求めます。

送信するデータと目的

タスクの計画・整理・診断の提案を生成するため、次の情報を、MacのCO[:V] Native HostとCodex CLIを通じてOpenAIへ送信します。

  • ユーザーが入力した文（やりたいこと・指示）
  • 対象と関連するタスクの名前、説明、期日、優先度、Focus Points、作業実績、タグ、ゴール（名前・期日・完了条件）、親子関係、着手状態（カスタム指示で対象を指定しないときは未完了タスク全体、AIタスク診断では画面に表示中の未完了タスク）
  • 登録タグの一覧と使用件数、ユーザーが固定した完了日・ゴール・タグ
  • 見積もりの参考にする完了タスクの名前と作業実績
  • AI日付診断では、候補外タスクの本文は送らず、日別の合計Focus Pointsだけ

本拡張機能が送信するのは上記の項目だけです。Vaultのパス、Markdownファイル全体、APIキー、閲覧履歴、Webページ内容、位置情報、端末識別情報、アナリティクスは送信しません。

処理経路とユーザー操作

  • 拡張機能から同一端末上のNative Hostへ、必要最小限の診断スナップショットを送信します
  • Native HostはVaultを直接読み書きせず、Codex CLIを実行してOpenAIから日付提案を受け取ります
  • 結果は提案として表示され、ユーザーが内容を確認・選択して反映を確定するまでタスク・ゴール・タグを変更しません
  • 開発者が運営するサーバーを経由せず、開発者がタスク内容を受信・閲覧することはありません

Codex CLIに対する制限

Codex CLIはユーザーのMac上で動作するため、しくみの上ではMac内のファイルを読むことができます。上記の送信内容を超える情報がAI処理へ取り込まれることを避けるため、本拡張機能のNative Hostは次の制限のもとでCodex CLIを起動します。

  • 書き込みを許可しないサンドボックス（--sandbox read-only）で実行し、ユーザーのCodex設定・スキル・プラグインを読み込みません
  • ファイル参照・コマンド実行・ブラウザ操作・コンピュータ操作に使う機能を無効化して起動します
  • 返ってきた提案を検査し、送信していない資格情報・秘密鍵・トークンに相当する文字列が含まれていた場合は、その結果全体を破棄してユーザーに通知します
  • 上記の制限が入っていない旧版のNative Hostでは、AIアシストを実行しません（更新手順を表示します）

APIキー設定

設定画面で任意に保存したAI APIキーはChrome Storage APIのローカル領域にのみ保持され、VaultやExport ZIPには含まれず、開発者へ送信されません。Mac向けAIアシスト（AI日付診断を含む）はこの設定値ではなく、ユーザー自身がログインしたCodex CLIを利用します。

AI機能をご利用の場合、送信されるデータの取り扱いについては、各AIサービス提供者のプライバシーポリシーもご確認ください。
  • OpenAI プライバシーポリシー

1. Introduction

This Privacy Policy describes how the Chrome extension "CO[:V]" (the "Extension") handles data. The Extension is developed and maintained by mock-n3, an individual developer based in Japan.

CO[:V] is a Chrome extension that manages tasks using plain Markdown (.md) files. It is designed with the utmost respect for user privacy and keeps standard task management on the device. Only when the user explicitly invokes the optional AI Assist (including the AI date diagnosis) does it send the minimum task data described in this policy to OpenAI.

2. Data Stored

The Extension stores the following data only on the user's device:

Data Type Storage Location Purpose
Task data (Markdown files) IndexedDB or local folder Task management and display
Extension settings Chrome Storage API (local) Preserving user preferences
AI API keys (optional) Chrome Storage API (local) Authentication for AI features
Storage Options Users can choose between two storage methods:
  • Browser-internal storage (IndexedDB) - Data is stored within the browser
  • Local folder (File System Access API) - Data is saved directly to a user-specified local folder

3. Data Not Collected Automatically

Except for content that users voluntarily enter into task fields, the Extension does not automatically collect any of the following:

  • Personally identifiable information (name, email, etc.)
  • Browsing history or browsing data
  • Usage analytics or telemetry
  • Location data
  • Device identifiers
  • Any other form of user tracking data
Standard task management does not transmit data to external servers. See the next section for the optional AI Assist (including the AI date diagnosis).

4. AI Integration

The Extension provides optional "AI Assist" features on macOS (Task Planner, Custom Instructions, and AI Task Diagnosis, including the AI date diagnosis used for rescheduling). They are not required for standard task management. They run only after the user reviews the disclosure, consents to "AI Assist", and clicks a run button (such as Create Suggestions or Start Diagnosis). The record of that consent is stored only on the user's own device, so the disclosure screen is not shown again on later runs. If the disclosure is revised, consent is requested again.

Data sent and purpose

To generate planning, organizing, and diagnosis suggestions, the following is sent to OpenAI through the local CO[:V] Native Host and Codex CLI:

  • Text the user enters (what they want to do, or instructions)
  • For target and related tasks: title, description, due date, priority, Focus Points, work records, tags, goal (title, due date, completion criteria), parent-child relationships, and work status (all open tasks when Custom Instructions has no target; the open tasks shown on screen for AI Task Diagnosis)
  • The list of registered tags with usage counts, and the due date, goals, and tags the user fixed
  • Titles and work records of completed tasks used as estimation references
  • For the AI date diagnosis, non-candidate tasks are sent only as aggregate Focus Points by date, without task text

Vault paths, complete Markdown files, API keys, browsing history, website content, location, device identifiers, and analytics are not sent.

Processing and user control

  • The Extension sends a bounded diagnosis snapshot to the Native Host on the same device
  • The Native Host does not read or write the Vault; it invokes the Codex CLI to obtain date suggestions from OpenAI
  • Suggestions do not change tasks, goals, or tags until the user reviews, selects, and explicitly applies them
  • No server operated by the developer is involved, and the developer does not receive or read task content

API key settings

AI API keys optionally saved in Settings remain in Chrome Storage on the device, are excluded from Vault and exported ZIP files, and are not sent to the developer. Mac AI Assist uses the user's signed-in Codex CLI rather than these saved settings.

If you use the AI features, please also review the privacy policies of the respective AI service providers for information on how they handle the data sent to their APIs:
  • OpenAI Privacy Policy

5. Permissions Used

The Extension uses only the following minimal permissions under Manifest V3:

Permission Purpose
sidePanel Display the task management UI in Chrome's side panel
storage Save extension settings and API keys within the browser
nativeMessaging (optional) Communicate with the CO[:V] Native Host on the same Mac only when the user invokes AI Assist
The Extension does not request access to web page content or remote code execution permissions.

6. Data Backup and Export

Users can manually export and import their data as ZIP files. This operation is performed entirely on the user's device and does not involve any data transmission to external servers.

7. Third-Party Data Sharing

The Extension does not sell, trade, lend, or share user data with any third party. Except for the minimum data sent to OpenAI after the user consents to and invokes the optional AI Assist (including the AI date diagnosis), user data never leaves the device.

8. Cookies and Tracking Technologies

The Extension does not use cookies, web beacons, pixel tags, or any other tracking technologies.

9. Children's Privacy

The Extension is not targeted at any specific age group and does not intentionally collect personal information from children. Users should not include personal or confidential information in task text if they do not want it sent by AI Assist.

10. Changes to This Policy

This Privacy Policy may be updated from time to time. Significant changes will be communicated through extension updates. The latest version of this Privacy Policy is always available on this page.

Version 0.8.7 improves the greeting in the upper-left corner so it reflects the time of day, phase of the week, and seasonal events. The selected greeting state is stored only in Chrome Storage on the user's device and is not transmitted externally.

Version 0.8.8 lets users enter a description (URLs or notes) when adding a task. As with the existing edit dialog, the description is saved only in the user's vault as part of the task and is not transmitted externally.

Version 1.0.0 expands the optional Mac feature into AI Assist, adding Task Planner, Custom Instructions, and AI Task Diagnosis for rescheduling, tags, and priorities. Because the data scope has expanded, the Extension invalidates prior consent, presents the revised disclosure, and requests explicit consent again. Suggestions do not write to the Vault until the user reviews, selects, and confirms what to apply.

Version 1.0.1 adds restrictions on the Codex CLI — file access, command execution, and browser or computer control are disabled, returned suggestions are screened for credentials, and an older Native Host without these restrictions is refused — and documents them in section 4. The data sent is unchanged, but because the disclosure now explains that the Codex CLI runs on the user's own Mac, the Extension invalidates prior consent and requests explicit consent again.

Version 1.1.0 improves goal selection when adding or editing tasks, adds tag archiving and restoration, and simplifies setup for the optional Mac AI Assist. Archived tags are hidden from standard tag views and input suggestions, and can be restored from the tag list without rewriting existing tasks; the data remains stored on the user's device. The scope of information sent to OpenAI by AI Assist, the consent flow, and extension permissions are unchanged.

Version 1.1.1 fixes an issue where the optional Mac AI Assist stopped from the second run onward. The Native Host now prevents the Codex CLI from extracting its bundled skills into the Codex working folder at startup and removes any leftovers before running. The Codex CLI restrictions described in section 4 are unchanged. The scope of information sent to OpenAI by AI Assist, the consent flow, and extension permissions are unchanged.

Version 1.1.2 improves how AI Assist and AI Task Diagnosis suggestions are applied. Changes that depend on a suggestion the user did not select are not applied, and the reason is shown for suggestions that cannot be applied. As before, suggestions do not write to the Vault until the user reviews, selects, and confirms what to apply. The scope of information sent to OpenAI by AI Assist, the consent flow, and extension permissions are unchanged.

Chrome Web Store Limited Use Compliance

User data handled by the Extension is used only to provide its disclosed single purpose of task management and the optional AI Assist planning, organization, and diagnosis suggestions within that purpose. User data is not used or transferred for advertising, retargeting, credit assessment, sale, or general market research. Neither the developer nor other humans are permitted to read users' task data.
